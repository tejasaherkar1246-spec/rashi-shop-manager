# Rashi Boutique & Daily Need - Shop Management System

A full-stack web application built for local retail businesses to manage daily sales, inventory stock levels, and customer credit (Udhari/Khata) in real time.

## Features
- **Smart Inventory & Stock Control:** Add, edit, and delete products with automatic stock deduction upon every sale.
- **Real-Time Stock Status:** Automatically flags items as *In Full Stock*, *Low Stock*, or *Out of Stock*.
- **Sales & Register Book:** Track transactions ranging from ₹1 to ₹1,00,000 with date/time logging.
- **Udhari (Credit) Ledger:** Tracks remaining balances per customer along with purchased items, with a one-click settlement option.
- **Sales Analytics Dashboard:** Summarizes daily, weekly, and monthly sales performance alongside total outstanding credits.
- **Persistent Local Storage:** Client-side data storage ensures records remain saved on device storage without requiring an external server setup.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Storage:** Browser LocalStorage API
- **UI Framework:** Vanilla JS with responsive CSS Grid/Flexbox design
